# Amazon広告 現場フィールドノート（運用代行ベテランの実務知見）

> 出典: 元Amazon運用者によるAmazon広告徹底解説（外部公開動画／2026年取得・固有名詞は匿名化）。
> 本ファイルは「現場の判断軸・打ち手」を記録する。**数値・規約の確定は platform-policy-check、商品名の文字数規約は Skill 16 を正本**とし、本ファイルの数字は現場体感（要都度照合）として扱う。
> 人格＝本Agent（運用代行ベテラン）の知見にそのまま吸収する素材。3者議論では現場派の根拠として使う。

## 1. なぜAmazon広告を使うのか（市場理解＝出さないと売れない市場）

- Amazonで広告を**使っていない販売者は1〜2割しかいない**。使わない＝競合に引けを取る前提。
- 支援事業者の平均で**売上の4〜5割（40〜60%）が広告経由**。残りがオーガニック。広告の売上インパクトはそれほど大きい。
- **広告を設定していないとSEOで不利になるロジックが存在する**（世に出回っていない）。広告を設定しただけで自然検索が上がる事例が多い。
- **Amazon検索順位の第一ロジック＝直近1ヶ月の販売個数**（オーガニックでも広告でもよい）。広告で販売個数を積めば検索順位も上がる。
- Amazonユーザーは**100%「買い物しに来ている」** → 検索KWが購買に直結、ROASが高く出やすい市場。Meta/Googleと違い「買う前提」。
- Amazon広告（特にSP）は**自然検索と同じ見た目で表示**され、ユーザーは広告と気づかない。上位枠を取るには広告が要る。
- **最終ゴール＝広告費がかからない自然検索売上の絶対額を上げること**。広告は「自然検索売上の絶対値を上げるための投資」。理想は自然検索比率を高めて広告依存度を下げる。

## 2. AI自動運用の落とし穴（「AI運用は論外」）

- Amazon専用の広告運用AIツールを使っている販売者は**ほぼ100%改善余地がある**（AIに任せきり＝伸び代の塊）。
- AIの強み＝**最短距離で60〜70点を取る**こと。逆に言うと細かい予算配分・キャンペーン別の最適化が苦手。
- 典型事故＝**AI側で予算上限を設定** → ROASが良いキャンペーンに予算が回らず消化されない。そこを外すだけで大幅改善。
- 体感比較：AIに月200〜300万投下 vs ベテランが月50万で入る → **ベテランの方が良い結果**。過去のAI置き換え事例で月商が倍以上になったケース多数。
- 診断サイン：**「予算が消化されていない高ROASキャンペーン」が放置されていないか**を真っ先に見る。

## 3. TACoS主導の予算設計（絶対値思想）

3指標の定義：
- **ACoS** ＝ 広告費 ÷ 広告経由売上（広告で売れた商品の原価計算に占める広告費の割合）
- **ROAS** ＝ 広告経由売上 ÷ 広告費（ACoSと分子分母が逆）
- **TACoS** ＝ 広告費 ÷ **アカウント全体売上（自然検索込み）** ← 最重要。ここにフォーカスする

商材別TACoSレンジ（現場体感／伸び切った後はほぼ定数）：

| 商材 | TACoS目安 |
|---|---|
| 化粧品 | 30%前後 |
| サプリメント | 25〜30% |
| 雑貨・トレーニング・中国OEM系 | 7〜10% |

- 伸び切った後は商材・原価・原率で水準が決まるため**TACoSはほぼ定数**扱いでよい。
- **「TACoSが下がっていればOK」ではない**。適切なレンジに収まっているかが本質。
- **TACoSが低すぎる＝広告を使わなさすぎ＝機会損失**。広告費は自然検索売上の「絶対値」を上げる手段なので、比率ではなく**絶対額の伸び**で判断する。
- 事例：B2B寄り商材（SSD/メモリ系）月商500万・広告費15万（TACoS≈5%） → TACoSを10%に引き上げ → 半年で月商1,500万（3倍）。**TACoSは上がったが自然検索売上と利益の絶対額が増えたので成功**。
- 「月商水準を上げる」こと自体が原価削減圧力になる（OEMはロット発注で原価が下がる）→ 規模拡大が最もレバレッジの効く打ち手。

## 4. 広告タイプの黄金比率とフェーズ別ステップアップ

主要広告タイプ：
- **SP（スポンサープロダクト）**：検索結果と全く同じ見た目。最もROASが良い。広告費の主役。
- **SB（スポンサーブランド）**：バナー/ロゴ/動画クリエイティブ。商品数が多い・SPが面で飽和してきたタイミング。ROASはSPより劣る。
- **SD（スポンサーディスプレイ）**：リターゲティング/カート下等。顧客データが溜まってから。
- スポンサードTV・**Amazon DSP**：月商数千万超の大手向け。ほとんどの販売者は上3つでよい。

**黄金比率（DSP除く・教科書的）：SP 7割／SB 1〜2割／SD 1〜2割**。

フェーズ別ステップアップ：
- 月広告予算10〜30万・月商〜200万：**SPのみ（オート＋マニュアル）で十分**。最もROASが出る。
- 商品ページCVRが整ってきたら：**SBを追加**して売上拡大。
- 月商500万前後・顧客データが溜まったら：**SDを追加**（セールタイミングのリターゲ等）。
- 余裕があれば初手からSBを出すのもあり。

注意：
- **予算配分ミスが非常に多い**。商品との相性があり、化粧品などはテレビCM的な動画（SB動画/スポンサードTV）の方がROASが良いこともある。基本比率を軸に商材で微調整。
- 500万以上かけられても**DSPを安易に使わない**。単体ROASが見えづらく（ラストクリック課金）、「100万使って何が出たの」になりがち。単純接触でCPCを下げたい意図が明確な時のみ。
- **AMC**＝一部代理店が使える分析ツール。ファースト/セカンドクリックも含めフルファネルで同線分析（ラストクリックの死角を補う）。

## 5. 指名キーワード（ブランドKW）防衛 ＝ 守りで必須

- 「指名で検索した客はどうせ自社を買う」は**大きな誤解**。競合が自社の指名KWにガンガン広告を出し、流入を奪っている。
- **守りで指名KWを入れていないと機会損失が激しい**。
- 事例：指名KWを追加しただけで月商70万 → 200〜300万。ほぼ1クリックで競合に流れていた売上が戻り、販売個数増 → 自然検索順位も底上げ。
- リスティングと違い、Amazonは**指名でも競合が出稿でき、競合商品ページにも広告を出せる**（ロジックが違う）。マーケ経験者ほど先入観に注意。
- 初期設定で確実にかける階層：
  - **第1層：ブランドKW（指名）** … 守りで必須
  - **第2層：商品ジャンルKW** … フレーズ一致（広告費を抑えるなら完全一致から → パフォーマンス良いものをフレーズ/部分一致へ昇格）
  - **第3層：周辺・代替KW**（例：お茶漬け商品の「振りかけ」「おつまみ」）… 広く CVR が落ちやすいので予算に余裕がある時に最後

## 6. オート→マニュアルの運用思想（両輪が原則）

- **オートターゲ**＝Amazonの機械学習が全KWを拾う。無駄打ちが多い（鮭茶漬けなのに「鮭の切り身」に出稿される等）。
- まず**2週間〜1ヶ月オートを回してKW単位でROASを分析** → 良いKW・カモにできる競合商品を**マニュアルへ昇格**。
- 基本：オートで立ち上げ → 徐々にマニュアルへ移行。既にKWが分かっている商材は初手から両方でもよい。
- **マニュアルだけはNG**。オートは「思いもしない超ロングテール（＝ROAS良いことが多い）」を拾う。
  - 役割分担：**マニュアル＝ビッグ/ミドルKW**、**オート＝ロングテール回収**。
- 慣れている人ほど「マニュアルだけ」にしがちだが機会損失になる。

## 7. 除外キーワード ＝ ACoS改善の最強手段

- **ACoS改善の最強手段は除外KW**。オートは広く、意図しないKWに出る（鮭茶漬け→鮭の切り身）。
- **オートもマニュアルも週次で除外KWをチェック**。マニュアルの部分/フレーズ一致・カテゴリーターゲも意図しない面に出るため、両方に除外を設定する。
- 頻度：自社運用なら**週次でよい**（プロは設定当日・翌日・毎日見る）。
- 判断のクリック閾値：
  - 判断には**20クリック以上**欲しい。早期判断なら**10クリックでCV有無**。
  - **ACoS 50%超**が除外の一つの目安。クリック10〜20以上溜まり成果が悪ければ即除外。
- 例外：**CVそのものを増やしたい初期フェーズは除外しすぎない**（フェーズに合わせる）。

## 8. タイトル＝広告CPCの関連性判定の唯一要素（最重要TIPS）

- 広告のCPCは「入札単価 × KWと商品ページの関連性」で決まる。この**関連性は商品タイトル（商品名）のみで判定される（広告では99.9%が商品名）**。
- 例：ホエイプロテインでCPCを下げたい → 商品名に「ホエイプロテイン」を**完全一致**で入れるだけでそのKWのCPCが**体感70〜80%水準までグッと下がる**。
- 狙う大きなカテゴリーのビッグKWが商品名に入っているかを**真っ先に改善** → アカウント全体のCPCが下がる。
- 実使用に合う用途語（鮭茶漬けの「振りかけ」「おつまみ」等、実際にその用途で使える前提）も入れるとCPC低下＋出稿面拡大。試す価値あり。
- **自然検索はKWを詰め込むと1語あたりの関連性が分散しうる**（広告では分散しない）。**KWは7〜10個に絞り、1語あたりの関連性を高める**。商品名は短く（文字数規約・カノニカルは Skill 16 が正本）。

## 9. ヒートマップとメイン画像（商品ページLPO）

- Amazon社内の購入者ヒートマップ（非公開）：**訪問者の約8割はページ下部（箇条書き・A+）を見ず**、メイン画像・サブ画像・タイトル・レビューしか見ない。**上部で勝負**。
- **メイン画像はCVRにも効く**。旧説「CTRはメイン画像／CVRはサブ画像」は更新中で、**メイン画像変更だけでCVR1.2倍**の事例がゴロゴロ。メイン画像もCVR意識で改善。
- タイトルは**変更すると一時的に検索順位が下がる**＋テスト回数に限りがある → **メイン/サブ画像でクリエイティブテスト（PGC）を回す**LPO的な動きで差別化。
- **白抜き画像の規制が緩和傾向**：パッケージと一緒に商品を写しパッケージにアテンションシール風の文字を入れる、化粧水ならテクスチャ表現を商品背後に置く等。楽天的な「サムネ命」に寄りつつある。緩和を見逃さずメイン画像で差別化（規制動向は platform-policy-check で都度照合）。
- レビューが高い王者に勝つ努力は**メイン画像（①）とA+（④）**で行う。

## 10. レビュー初動設計（ローンチ・規約準拠）

- レビューはCVRの命。**レビュー2桁未満の商品はほぼ買われない**。
- **0個で本格出稿しても無駄**。最低10個溜まるまで緩めに広告 → 10個溜まったらガンガン出す。
- 規約準拠の獲得法：
  - **同梱チラシでフラットにレビュー依頼＝OK**（届く状態のチェックも込みで設計）。
  - **インセンティブ付与・星の指定＝NG**（特典付与/ステマ規制違反）。
  - **Amazon公式レビューリクエスト機能**（定型メール）でレビュー率が**約1%→3〜4%**に上がる。
  - インフルエンサーに「ローンチします」とコンテンツ化して**フラットに応援依頼＝OK**。
- まず初動10個の確保を最優先に積み上げる。

## 11. 自社運用 vs 代理店の使い分け

- 月広告予算10〜30万：**スポットコンサル**でアドバイスを受ける。
- 月広告予算50〜500万：**運用代行に委託**し、事業者は**メーカー機能（顧客インサイト・市場課題・商品開発・ブラッシュアップ）にリソース集中**。
- 成果が出しやすい（＝伸び代が大きい）アカウントの典型：
  - **AI任せの運用**になっている
  - 広告を**初期設定のまま1〜2ヶ月触っていない**
  - メイン画像が**初期の白抜きのまま放置**
- CPCトレンド：既存広告メニューのCPCが高騰 → **単純接触回数を増やしてCPCを下げる**工夫、DSP（配送箱広告等）。総合格闘技化が進行。

## まとめ（現場の優先順位）

1. **商材別の適切なTACoSレンジに収める**（ここの調整だけで売上が大きく動く・絶対値で判断）
2. **指名KWを守りで必ず入れる**（競合奪取の機会損失を止める）
3. **オート＋マニュアルの両輪＋週次の除外KW**でACoSを締める
4. **ビッグKWを商品名に入れてアカウント全体のCPCを下げる**（関連性は商品名のみ）
5. **メイン画像をCVR起点で回す**（ヒートマップ上部で勝負）
6. **レビュー初動10個**を作ってから本格出稿
7. **AI任せ・初期設定放置・白抜き放置**は伸び代サイン
