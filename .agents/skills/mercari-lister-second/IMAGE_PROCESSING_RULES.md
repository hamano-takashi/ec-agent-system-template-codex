# 画像加工ルール

メルカリ出品・編集でトップ画像にタイトルタグや送料無料バッジを入れる場合は、以下を必ず守る。

## 1枚目画像

- 1枚目は訴求用のトップ画像として、タイトルタグや送料無料バッジを配置してよい。
- ただし、商品本体が見えづらくならないよう、帯・文字・バッジは商品を大きく隠さない位置に置く。
- `mercari-lister-second` では、タイトル帯はゴールド半透明、文字はネイビー、送料無料バッジは丸タイプで濃いめのピンクを基本とする。

## 2枚目画像

- 1枚目にタイトルタグや送料無料バッジを入れた場合は、必ず同じ元画像を使って、テキスト・バッジなしの画像を2枚目として追加する。
- 2枚目は商品確認用として、明るさ・コントラスト・白背景を整えた見やすい加工にする。
- 2枚目には、タイトル文字、帯、送料無料バッジ、装飾テキストを入れない。
- 2枚目は1枚目の直後に配置し、以降の画像はその後ろに並べる。

## 目的

- 1枚目で一覧画面の訴求力を高める。
- 2枚目で商品本体の形・色・状態を確認しやすくする。
- タイトルタグやバッジによって商品が隠れて見えづらくなる問題を防ぐ。
