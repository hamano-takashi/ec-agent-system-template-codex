# mercari-lister-second 重要追記

このファイルは `mercari-lister-second` スキルの上書きルールです。
既存の `SKILL.md` が文字化けしている場合でも、この内容を優先して従ってください。

## 新規出品自動化・再編集防止ルール

- chakiアカウントで新規出品を検知した場合、`mercari-lister-second` の編集ワークフローをその場で自動開始する。
- 再出品は新規出品として扱い、検知した時点で待機せず自動編集を開始する。
- ただし、このスキルで一度検知した商品でも、画像編集が未完了なら再編集対象に戻す。
- 画像編集が未完了の再出品は、画像だけでなくタイトル・説明文・カテゴリなど関連項目もまとめて編集する。
- 画像編集が完了していても `marketResearchLogged` が `true` でない商品は未完了として扱い、市場調査とスプレッドシート記録だけを自動実行する。
- このスキルで画像編集と市場調査記録まで完了した商品だけを、以後は何も編集しない対象とする。
- 自動化で編集する前に、必ず `.tools/mercari/mercari-lister-second-edited-items.json` を確認する。
- 検知した実行の中で、スキップ・市場調査のみ・フル編集のどれに当たるかを即判定し、そのまま処理へ進める。
- 一覧で確認できた未処理の新規出品・再出品が複数ある場合は、1件処理して終わらず、同じ実行の中で未処理がなくなるまで続ける。
- 未処理商品が残ったまま正常終了してはいけない。途中で止まる場合は、どの商品が未処理かを記録し、次回はその商品から再開する。
- `https://jp.mercari.com/sell/edit/<itemId>` を開いてもフォーム項目が描画されない場合は、編集失敗を黙って飲み込まず、その商品をブロッカーとして記録し、市場調査キューと作業報告へ必ず残す。
- 商品IDまたは商品URLが編集済み管理ログに存在しても、`imageEdited` が `true` でなければ未完了として編集を行う。
- 商品IDまたは商品URLが編集済み管理ログに存在し、`imageEdited` が `true` かつ `marketResearchLogged` が `true` でなければ、出品ページの項目は変更せず、市場調査とスプレッドシート記録だけを行う。
- 商品IDまたは商品URLが編集済み管理ログに存在し、`imageEdited` が `true` かつ `marketResearchLogged` が `true` の場合のみ、タイトル・説明文・画像・価格・カテゴリなどを一切変更せず、「画像編集と市場調査記録まで完了済みのためスキップ」と記録する。
- 自動化で編集を完了した商品は、商品ID・商品URL・編集日時・反映内容の概要に加え、`imageEdited`、`descriptionEdited`、`titleEdited`、`categoryEdited`、`marketResearchLogged`、`relistedAtCheck` を編集済み管理ログへ追記する。
- 自動化中でも価格変更は勝手に行わない。既存価格を維持するか、価格承認が必要な場合は編集を止めてユーザー確認に回す。
- 自動化では、編集反映の直後に市場調査とスプレッドシート記録まで続けて実行し、`marketResearchLogged` が `true` になるまで完了扱いにしない。
- 編集反映後は `.tools/mercari/mercari-lister-second-market-research-pending.json` に対象商品を必ず追加する。スプレッドシート記録まで終わればキューから外し、終わらなければ未完了として残す。
- 自動化で新規出品・再出品・オークション形式をまとめて処理する場合は、`.tools/mercari/chaki_auto/run_auto_edit.js` を優先的に使う。このランナーは公開プロフィール検知 → 編集済みログ照合 → 未編集商品の抽出 → 画像・タイトル・説明文の反映 → 市場調査キュー追加までを一括で行う。
- オークション形式の商品でも自動化対象から外さない。価格入力欄は `price` と `auctionPrice` の両方を考慮し、表示中の価格は変更しないまま編集を進める。

## 価格編集ルール

- 出品価格は勝手に決定・変更しない。
- 相場調査をした場合でも、価格欄へ反映する前に必ずユーザーの指示・承認を待つ。
- ユーザーへ承認や指示確認を依頼する文面は、必ず日本語で記載する。
- 明らかな桁違い・入力ミスに見える場合も、推奨価格と理由を提示するだけに留める。
- ユーザーが明示的に「その価格で変更して」と指示するまで価格を保存しない。
- 既存価格を維持する場合は、その旨を作業報告に明記する。
- 自動化では、出品日または再出品日当日の相場調査結果を Google スプレッドシートへ記録する。記録先は `.tools/mercari/mercari-lister-second-market-research-sheet.json` を参照する。
- スプレッドシート記録は価格変更の代替ではなく、価格検討用の台帳として扱う。
- 記録した推奨価格は保存画面へ反映しない。

## chaki用トップ画像デザイン

- 1枚目画像のタイトル帯は、ゴールドの半透明帯にする。
- 1枚目画像のタイトル帯テキスト色はネイビーにする。
- 送料無料などのバッジは丸タイプにする。
- バッジ色は濃いめのピンクにする。
- 画像加工時は商品本体を隠しすぎない。
- 帯・バッジは視認性を確保しつつ、商品が主役になる配置にする。

## 相場調査ルール

- 今後の相場調査では、同ディレクトリの `MARKET_RESEARCH_RULES.md` を必ず参照する。
- スプレッドシート記録では、同ディレクトリの `SPREADSHEET_RULES.md` を必ず参照する。
- メルカリ・ヤフオク・Yahoo!フリマ・Amazon の4プラットフォームで調査する。
- 各プラットフォームごとに、過去6か月以内に売れた商品の最高価格・最安価格・平均価格・確認件数を表示する。
- 実売データを確認できない場合は、推測で数字を作らず「取得不可」と明記する。
- 現在価格や類似商品の価格は、実売データではなく参考価格として分けて表示する。
- 価格欄への反映は、ユーザーが明示的に金額を承認してから行う。
- 相場調査結果は、商品ごとに Google スプレッドシートへ追記する。
- 自動化では `checkedDate` に再出品確認日を入れ、`priceStatus` は `kept` または `research_only` とする。
- 市場調査だけを行った商品も、編集済み管理ログの `summary` に「市場調査のみ追記」を残し、`editedAt` を更新する。

## 画像加工ルール

- 今後の画像加工では、同ディレクトリの `IMAGE_PROCESSING_RULES.md` を必ず参照する。
- 1枚目にタイトルタグ・送料無料バッジを入れる場合は、同じ元画像をテキスト・バッジなしで明るく加工した画像を2枚目として追加する。
- 2枚目は商品確認用のため、タイトル文字・帯・バッジ・装飾テキストを入れない。

## タイトル作成ルール

- 今後のタイトル作成では、同ディレクトリの `TITLE_RULES.md` を必ず参照する。
- 英語表記と日本語表記の両方を入れると文字数を圧迫するブランドは、日本語表記のみをタイトルに入れる。
- 英語表記は商品説明欄と検索キーワードに入れる。
- ナイキ（Nike）のように短く、40文字以内で重要語を十分入れられる場合は、英語表記と日本語表記の両方をタイトルに入れてよい。
