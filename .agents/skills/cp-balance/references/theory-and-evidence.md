# C/Pバランス理論・根拠メモ

## 1. 確認済みの中心定義

C/Pバランス理論では、商品力を次の2つに分ける。

- C（商品コンセプト）: 買う前に欲しいと思わせる力。
- P（商品パフォーマンス）: 買った後に買ってよかったと思わせる力。
- 両方が高い商品を、トライアルとリピートがともに生まれる「成功商品型」と捉える。

これは「費用対効果」を意味するCost Performanceとは別の概念である。

## 4. 検証済みと未検証を分ける

### このスキルで使用してよい中心命題

- Cは購入前評価、Pは購入後評価である。
- C高・P低では初動後に失速しやすい。
- C低・P高では利用者の評価が高くても初回購入が増えにくい。
- CとPを別々に測定する必要がある。

これらは理論上の診断枠組みとして使う。特定商品の売上を保証する因果法則として断定しない。

### 原典確認なしに転載・断定しない主張

セミナー内には市場シェア、成功率、継続年数などの数値が表示されていたが、この作業では調査母集団・定義・計算過程・原典データまで検証していない。次の種類の主張は、提案書・広告・商品説明へ転用する前に `fact-check` を通す。

- 「2つに1つ」「100倍」などの成功確率比較
- 「10年以上シェアNo.1」などの順位・継続実績
- 特定カテゴリーや商品のシェア・成功事例
- 理論の発表年、検証年数、サンプル数を伴う権威づけ

## 5. 解釈上の注意

1. 運用上はCとPを直列ゲートとして扱う。これは片方の高得点で他方の不足を相殺させないための本スキル上の安全設計である。
2. Cは広告想起だけではない。ニーズ、便益、カテゴリー理解、信頼性、価格受容を含む商品概念全体である。
3. Pはスペックだけではない。約束した便益の実現、使用のしやすさ、品質安定、購入後サービスを含む。
4. トライアルとリピートはC/Pの有力な観測指標だが、配荷、価格、競合、在庫、広告接触などの交絡を除く必要がある。
5. 耐久財・低頻度商材では、実再購入だけでPを判断しない。継続使用、推奨、関連購買などを事前定義する。
